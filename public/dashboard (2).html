브랜드검색 셋팅파일 URL 매칭 대시보드

최종URL 파일과 소재 세팅 파일, 두 개를 올리면 소재명 규칙(기기·구/신사명·범용/보종·영역)에 맞춰 URL을 자동으로 매칭해요. 결과를 바로 확인하고, 매칭이 반영된 엑셀 파일을 다운로드할 수 있어요.

이번 소재명 "소재 세팅 분배" 시트의 I열(금번 세팅 소재)·J열(소재명 변경)을 이 텍스트로 자동 교체해요. 뒤쪽 날짜(0819 등)는 대시보드를 실행하는 오늘 날짜로 자동으로 바뀌어요.

매칭 상세

시트셀영역 표기매칭된 URL
동작 방식 — 이 페이지는 모든 계산을 사용자의 브라우저 안에서 수행해요. 파일이 서버로 업로드되지 않고, 같이 쓰는 다른 팀원도 이 링크를 열어 각자의 파일 2개로 바로 사용할 수 있어요.
원본 보존 — 다운로드 파일은 원본 엑셀 파일의 압축 구조를 그대로 열어서 G열의 URL 셀만 딱 골라 수정하는 방식이에요. 그 외 이미지, 표 서식, 다른 셀 값 등은 전혀 건드리지 않아서 원본 그대로 유지돼요.
영역 자리 판단 방식 — G열에 이미 적혀 있는 값(이전 URL이나 이전 결과)은 보지 않고, 각 블록의 정해진 순서(홈링크→브랜드소식→메인이미지→타이틀→…)를 기준으로 자리를 판단해요. 그래서 G열에 예전 URL이 남아있어도 먼저 지우고 새 URL로 다시 채워요.
